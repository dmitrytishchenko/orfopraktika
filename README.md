# ОрфоПрактика

Тренажёр орфографии для 5 класса: 20 тем, 320 заданий, мини-диктант, «Найди ошибку», вопрос «Почему так пишется?» и интервальное повторение. Работает в браузере, как приложение с сайта или как APK для Android — везде без интернета; ответы хранятся только на устройстве ученика.

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | Весь тренажёр. Можно открыть просто как файл. |
| `manifest.webmanifest`, `icons/` | Описание приложения и иконки для установки на телефон. |
| `sw.js` | Офлайн-режим: после первого открытия сайт работает без интернета. |
| `android/` | Android-приложение (APK) с тренажёром внутри. |
| `tests/test_app.py` | Браузерные тесты. |
| `.github/workflows/tests.yml` | Запуск тестов на GitHub при каждом изменении. |
| `.github/workflows/android.yml` | Сборка APK на GitHub и публикация в Releases. |
| `.nojekyll` | Говорит GitHub Pages отдавать файлы как есть. |

## Выложить на GitHub Pages

1. Создайте на GitHub публичный репозиторий, например `orfopraktika`, без README.
2. Загрузите файлы из этой папки:

   ```bash
   cd orfopraktika
   git init
   git add .
   git commit -m "ОрфоПрактика"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/orfopraktika.git
   git push -u origin main
   ```

   Если стоит GitHub CLI, хватит одной команды после `git commit`:
   `gh repo create orfopraktika --public --source=. --push`

3. В репозитории откройте **Settings → Pages**. В блоке «Build and deployment» выберите **Source: Deploy from a branch**, ветку **main** и папку **/(root)**, нажмите **Save**.
4. Через минуту-две сайт откроется по адресу `https://ВАШ_ЛОГИН.github.io/orfopraktika/`.

Обновления: поменяли файлы → `git commit` → `git push`. Сайт обновится сам, а установленное приложение подхватит новую версию при следующем запуске с интернетом. Если меняли иконки или манифест, увеличьте номер в строке `const CACHE = 'orfopraktika-v1'` в `sw.js`.

## Установить на телефон Android

1. Откройте адрес сайта в **Chrome** на телефоне.
2. Меню **⋮ → «Установить приложение»** (в некоторых версиях — «Добавить на главный экран»). Ещё проще: в тренажёре откройте **Настройки → Приложение на телефон → Установить приложение**.
3. На главном экране появится иконка «ОрфоПрактика». Приложение открывается без адресной строки и работает без интернета.

Мини-диктант читает слова голосом телефона. Если ничего не слышно: **Настройки Android → Специальные возможности → Синтез речи** — выберите русский язык и скачайте голос.

## APK для Android

В папке `android/` — приложение, внутри которого лежит тот же `index.html`. Оно работает без интернета и без сайта: мини-диктант читает слова голосом Android, резервные копии и отчёты сохраняются туда, куда вы выберете, кнопка «Назад» возвращает на главную.

**Где взять APK.** После загрузки репозитория на GitHub workflow `android-apk` сам собирает приложение при каждом изменении `index.html` и кладёт его в **Releases**. Постоянная ссылка для телефона:

`https://github.com/ВАШ_ЛОГИН/orfopraktika/releases/latest/download/OrfoPraktika.apk`

Откройте её на телефоне, скачайте файл, откройте его и разрешите установку из этого источника.

**Ключ подписи — обязательно.** Ключ лежит в отдельном архиве `orfopraktika-signing-key.zip`; в репозиторий его не кладите. Добавьте два секрета в **Settings → Secrets and variables → Actions**:

| Секрет | Значение |
|---|---|
| `ORFO_KEYSTORE_BASE64` | содержимое файла `orfopraktika.jks.base64` |
| `ORFO_KEYSTORE_PASSWORD` | содержимое файла `password.txt` |

Или из папки с ключом:

```bash
gh secret set ORFO_KEYSTORE_BASE64 -R ВАШ_ЛОГИН/orfopraktika < orfopraktika.jks.base64
gh secret set ORFO_KEYSTORE_PASSWORD -R ВАШ_ЛОГИН/orfopraktika < password.txt
```

Без секретов APK подписывается временным ключом, и каждую новую версию придётся ставить только после удаления старой — а вместе с приложением удаляются и ответы. Сохраните ключ в надёжном месте: если его потерять, обновить установленное приложение поверх не получится.

**Собрать самому.** Откройте папку `android/` в Android Studio и выберите **Build → Build APK(s)**. `index.html` копируется в приложение автоматически при каждой сборке.

## Перенос истории

У файла на компьютере, у сайта, у установленного с сайта приложения и у APK разные хранилища. Чтобы перенести ответы: **Настройки → Скачать копию JSON** в одном месте, затем **Загрузить копию → Объединить** в другом. Копия сохраняется отдельно для каждого ученика.

## Добавить задания

Задания лежат в начале `index.html`, в массиве `TOPICS`. Каждое задание — `[номер, 'текст с [пропуском]', 'пояснение', номер правила]`:

- Номер постоянный. Не меняйте его и не отдавайте другому заданию, иначе история ответов перейдёт к чужому слову. Новому заданию — следующий свободный номер в теме.
- `[]` — вставлять ничего не нужно.
- Номер правила нужен для вопроса «Почему так пишется?» (список `reasons` в теме). В темах с `reasonMap` он выводится из ответа сам.

После правки запустите тесты — они проверят, что в каждом задании ровно один пропуск, номера не повторяются и у каждого задания есть правило.

## Тесты

```bash
pip install playwright
python -m playwright install chromium
python tests/test_app.py
```

Тесты проходят по всем режимам, проверяют хранение и миграцию данных, профили, импорт, две вкладки и офлайн-режим. Скриншоты сохраняются в `tests/screenshots/`.
